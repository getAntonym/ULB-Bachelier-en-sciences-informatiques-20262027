# Mémoire primaire

## 3.1.1 — Structure et adresses

mémoire temporaire, de travail.

$\approx$ qlq Go

2 opérations:

- lecture: on récupère une donnée

- écriture: on modifie une donnée

La mémoire est découpée en cases de taille fixe (1 octet), et chaque case a
un numéro = adresse mémoire.

$\mapsto$ écriture(donnée d, adresse a)

$\mapsto$ lecture(adresse a)

## 3.1.2 — Mémoire cache

stocke dans le CPU une copie d'une partie des informations
de la mémoire centrale.

Elle est $+$ rapide, mais plus petite.

Quand le CPU fait une lecture

- si la donnée est en cache $\mapsto$ cache hit

- sinon $\mapsto$ cache miss

L'efficacité repose sur le fait que la cache est correctement alimentée.

On essaye de prédire les infos dont le CPU aura besoin pour les charges dans la cache.

En pratique on a plusieurs niveaux de cache

- qlq octets= Regristres

- qlq Ko = L1, le plus rapide

- qlq Mo = L2, le plus lent

- qlq Go = Mémoire centrale
