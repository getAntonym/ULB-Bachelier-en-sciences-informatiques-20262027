# Mémoire primaire

## Rôle et organisation

> [!NOTE]
> **Mémoire de travail**
>
> La mémoire primaire est une mémoire temporaire, utilisée pour le travail de l’ordinateur.
>
> Ordre de grandeur noté en cours : **quelques Go**.

### Structure et adresses

La mémoire est découpée en **cases de taille fixe de 1 octet**. Chaque case possède un numéro : son **adresse mémoire**.
### Lecture et écriture

| Opération | Rôle | Notation |
| :--- | :--- | :--- |
| **Lecture** | Récupérer une donnée à une adresse | `lecture(adresse a)` |
| **Écriture** | Modifier une donnée à une adresse | `écriture(donnée d, adresse a)` |

## Mémoire cache

La mémoire cache stocke dans le CPU une **copie d’une partie des informations de la mémoire centrale**.

> [!IMPORTANT]
> **Compromis**
>
> La mémoire cache est **plus rapide**, mais **plus petite** que la mémoire centrale.

### Succès et échec de cache

Quand le CPU effectue une lecture :

| Situation | Terme |
| :--- | :--- |
| La donnée est présente dans le cache | **Cache hit** — succès |
| La donnée n’est pas présente dans le cache | **Cache miss** — échec |

### Efficacité du cache

L’efficacité repose sur le fait que le cache est correctement alimenté. On essaye de prédire les informations dont le CPU aura besoin pour les charger dans le cache.

### Repères dans la hiérarchie mémoire

| Élément | Ordre de grandeur noté en cours | Repère |
| :--- | :--- | :--- |
| **Registres** | Quelques octets | Dans le CPU |
| **Cache L1** | Quelques Ko | Plus rapide que L2 |
| **Cache L2** | Quelques Mo | Plus lent que L1 |
| **Mémoire centrale** | Quelques Go | Mémoire de travail |

> [!WARNING]
> **À vérifier et à préciser**
>
> Ces capacités sont des repères issus des notes, pas des valeurs universelles. Les registres et la mémoire centrale ne sont pas des niveaux de cache. La hiérarchie peut aussi comporter un cache L3.

## Ordre des octets dans les mots

Supposons qu’on ait un entier sur **32 bits**.

> [!NOTE]
> **À compléter**
>
> Cette partie est seulement amorcée dans les notes d’origine.
